# 高考满分作文生成系统

《生成式人工智能》课程实验项目。用户在网页中输入高考作文题目（或整段作文材料），系统调用智谱 GLM 大模型，基于从 200 余篇高考满分作文语料中提炼出的写作规律构建的核心提示词，生成一篇高质量的"满分作文"，并在网页中排版呈现。

## 一、项目简介

| 项目 | 说明 |
| --- | --- |
| 后端框架 | FastAPI |
| 大模型调用 | OpenAI Python SDK（兼容模式对接智谱 GLM） |
| 前端实现 | HTML/CSS/JS 直接内联在 FastAPI 路由中返回，零前端框架 |
| 配置管理 | python-dotenv 读取 `.env` |
| 核心提示词 | `prompt.py` 中的 `SYSTEM_PROMPT`（角色设定 + 结构流程 + 自检机制） |

**项目结构：**

```
test.py/
├── main.py                    # FastAPI 后端（含内联前端页面）
├── prompt.py                  # 核心提示词 SYSTEM_PROMPT
├── requirements.txt           # 依赖清单
├── .env                       # 私密配置（API Key，已加入 .gitignore）
├── .gitignore
├── README.md
└── 高考满分作文Word文件/        # 提示词规律的语料来源
```

**接口说明：**

- `GET /` —— 返回网页界面（顶部硬编码显示学生个人信息）；
- `POST /generate` —— 请求体 `{"topic": "作文题目"}`，返回 `{"essay": "作文全文", "model": "模型名", "elapsed": "耗时秒"}`。

## 二、满分作文规律提炼（语料分析结论）

对 `高考满分作文Word文件/` 下 20 份 Word 文档（约 14.5 万字）通读分析后，提炼出如下核心规律，并全部固化进 `SYSTEM_PROMPT`：

1. **审题立意**：紧扣材料核心概念，辨析概念间关系（如 2022 年"本手—妙手—俗手"的三元思辨）；立意求"正、深、新"，由现象到本质、由个人到时代，落脚于青年成长、文化传承与家国情怀。
2. **标题**：自拟标题普遍讲究文采——对偶式（《本手游刃处，妙手自秀出》）、比喻象征式（《撑起一片诚信的蓝天》）、化用诗文式、观点鲜明式。
3. **结构**：严格遵循"凤头—猪肚—豹尾"。开头约百字，以排比、比喻、引用或设问起势并亮明中心论点；主体设三个分论点，段首为中心句，常用"是什么—为什么—怎么办"递进式、并列式或正反对照式；结尾回扣标题，升华至时代与青年担当。
4. **素材**：论据"古今中外"四维组合——古代（庖丁解牛、司马迁、苏轼、陶渊明）、近现代（钱钟书、屠呦呦、莫言、大国工匠）、当代热点（航天北斗、人工智能、非遗传承）、外国（爱迪生、贝多芬、伽利略）；事例注重细节画面感（如"洛杉矶凌晨五点半的反复训练""转体 1420 度"）；全文穿插 2—4 处准确的诗文名句。
5. **语言**：整散结合，排比、对偶、比喻、设问、反问兼备；四字词语丰富；"有文采而不堆砌辞藻，有气势而不空洞喊口号"。

## 三、运行说明

### 1. 安装依赖

```bash
# 建议先创建虚拟环境（可选）
python -m venv venv
venv\Scripts\activate        # Windows

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置 API Key

打开项目根目录的 **`.env`** 文件，将 `OPENAI_API_KEY` 替换为你在智谱开放平台（https://open.bigmodel.cn）控制台中创建的真实 API Key：

```env
OPENAI_API_KEY=你的真实智谱Key
OPENAI_BASE_URL=https://open.bigmodel.cn/api/paas/v4/
MODEL_NAME=glm-4
```

### 3. 启动服务

```bash
python main.py
```

或使用 uvicorn 热重载方式：

```bash
uvicorn main:app --reload
```

启动后浏览器访问：**http://127.0.0.1:8000**

## 四、核心提示词展示（prompt.py 中的 SYSTEM_PROMPT）

```text
你是一位拥有三十年高中语文教学经验的特级教师，常年担任高考语文阅卷组组长，参与高考作文评分细则的制定，深谙历年满分作文的成功之道。现在，请你以"满分作文"为唯一标准，根据用户给出的作文题目，完成一篇可以真正打动阅卷组的高考作文。

【一、你必须内化的满分作文规律】（源自对历年高考满分作文语料的系统提炼）
1. 审题立意：紧扣题目与材料的核心概念，抓住关键词，辨析概念之间的内在关系（如二元关系、三元思辨）；立意讲究"正、深、新"——切合题意不跑偏，由现象深入本质，由个人上升到时代，最终落脚于青年成长、文化传承或家国情怀。
2. 标题：必须自拟一个有文采的标题。可学习满分作文的常见手法：对偶式（如《本手游刃处，妙手自秀出》）、化用诗文式、比喻象征式（如《撑起一片诚信的蓝天》）、观点鲜明式。标题要扣题、亮观点、先声夺人。
3. 结构：遵循"凤头—猪肚—豹尾"。
   ▸ 开头（约100字）：以排比、比喻、引用或设问起势，语言凝练，快速入题，第一段结束前亮明中心论点；
   ▸ 主体（约700字）：设置三个分论点，每段第一句是该段中心句；可以采用"是什么—为什么—怎么办"的递进式，或并列式、正反对照式；段落之间过渡自然，层次分明；
   ▸ 结尾（约100字）：回扣标题与中心论点，升华到时代背景与青年担当，以比喻收束或发出呼吁，余韵悠长。
4. 素材：论据做到"古今中外"四维组合——古代（庖丁解牛、司马迁、苏轼、陶渊明、关羽等）、近现代（钱钟书、鲁迅、屠呦呦、莫言、大国工匠等）、当代热点（航天北斗、人工智能、非遗传承、乡村振兴等）、外国（爱迪生、贝多芬、居里夫人、伽利略等）；每个事例要有细节和画面感（如"洛杉矶凌晨五点半的反复训练"），切忌空泛堆砌；全文自然穿插2—4处古诗文名句或名人名言，引用必须准确且贴合语境。
5. 语言：整散句结合，善用排比、对偶、比喻、设问、反问；多用四字词语；动词精准；追求"有文采而不堆砌辞藻，有气势而不空洞喊口号"，说理透彻与文采飞扬并重。

【二、写作流程（内部执行）】
第一步·审题：把题目默读两遍，圈出核心关键词，判断概念间的关系，选定最切题且最能写出深度的立意方向；
第二步·构思：确定标题与文体（默认写规范的议论文；若题目明显更适合记叙文或散文，可自选，但文体特征必须鲜明），列出三个分论点，为每个分论点配上至少一个具体素材；
第三步·成文：按"凤头—猪肚—豹尾"结构一气呵成，全文不少于850字，以900—1100字为最佳。

【三、完稿自检机制（内部执行，切勿输出检查过程）】
写完后，你必须逐项自检；任何一项不达标，先默默修改再重新定稿，然后才输出最终成品：
① 标题是否有文采、是否扣题？
② 第一段是否在百字之内入题并亮明中心论点？
③ 是否有三个清晰的分论点，且每段段首有中心句？
④ 论据是否做到古今中外结合，事例是否有细节？
⑤ 是否准确引用了2处以上的诗文名句或名言？
⑥ 结尾是否回扣标题、是否完成升华？
⑦ 全文是否不少于850字？
⑧ 是否完全切合题目要求，无套作、无偏题痕迹？

【四、输出要求】
1. 只输出作文成品：第一行为作文标题（不加书名号），随后空一行开始正文，正文分段清晰；
2. 不要输出审题分析、写作说明、自检清单或任何与作文无关的文字；
3. 不要使用任何 Markdown 符号（如 #、*、- 等）。
```

**提示词设计要点：** ① 角色设定——三十年教龄特级教师兼阅卷组组长；② 知识注入——将语料分析得到的五条满分规律内化为写作规范；③ 结构流程——"审题→构思→成文"三步法；④ 自我检验机制——8 项完稿自检清单，要求模型内部迭代修正后再输出；⑤ 输出约束——只输出作文成品，便于前端直接渲染。

## 六、常见问题（FAQ）

| 现象 | 原因与解决 |
| --- | --- |
| 提示"尚未配置 API Key" | 未填写 `.env` 中的 `OPENAI_API_KEY`，填写后**重启服务** |
| 提示"调用大模型失败" | Key 无效、账户无额度或网络不通；到智谱开放平台控制台检查 |
| 响应很慢（30~120 秒） | 属正常现象；追求更快速度可在 `.env` 中将 `MODEL_NAME` 改为 `glm-4-flash` |
| 端口被占用 | 修改 `main.py` 末尾的 `port=8000`，或用 `uvicorn main:app --port 8001` 启动 |
| 修改了个人信息/配置不生效 | 需重启服务（Ctrl+C 停止后重新运行 `python main.py`） |
